# Images Folder

Place your wavy header image here.

## Required Image:
- **wavy_header.png** - The wavy green header image for the login screen

## Image Specifications:
- **Format**: PNG (preferred for transparency) or JPG
- **Dimensions**: 
  - Width: Should be wide enough to cover mobile screens (recommended: 800-1200px wide)
  - Height: ~200-300 pixels
- **Design**: Green wavy shape on transparent or black background
- The wavy design should flow horizontally across the image

## How to Add Your Image:

### Option 1: From Figma
1. Export the wavy header from Figma as PNG
2. Name it `wavy_header.png`
3. Copy it to this folder: `flutter_application_1/assets/images/`
4. Run `flutter pub get` in your terminal

### Option 2: Save from Browser/Design Tool
1. Right-click on the wavy header image
2. Save it as `wavy_header.png`
3. Copy it to this folder: `flutter_application_1/assets/images/`
4. Run `flutter pub get` in your terminal

### After Adding:
- The app will automatically display your image
- If the image is not found, you'll see a gradient fallback with a placeholder message
- Make sure the image path matches exactly: `assets/images/wavy_header.png`
